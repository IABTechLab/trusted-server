# Kargo integration status

Trusted Server does not ship a native Kargo integration, so there is no
`kargo` module to select or configure.

Kargo can be used only as upstream demand through a separately configured
OpenRTB or Prebid Server path when the publisher and upstream service support
it. Trusted Server does not provide Kargo-specific request translation,
viewability measurement, creative formats, or reporting.

Use the [Integrations overview](/guide/integrations-overview) for the current
integration inventory and [Auction orchestration](/guide/auction-orchestration)
for the generic demand source configuration.
